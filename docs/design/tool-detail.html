MCP 服务 / mysql-query / query_data
query_data search
执行只读 SQL 查询，返回结果集（限制 1000 行），用于数据探查和验证
所属服务: mysql-query
能力类型: search
是否有副作用: 否
标签: 查询 SQL 只读
Input Schema
定义该工具接受的参数结构
字段名 类型 必填 说明
database string 是 目标数据库名称
sql string 是 要执行的 SQL 查询语句，仅支持 SELECT / SHOW / DESCRIBE
limit integer 否 返回结果的最大行数，默认 100，上限 1000
timeout_seconds integer 否 查询超时时间（秒），默认 30
JSON Schema 
{
  "type": "object",
  "properties": {
    "database": {
      "type": "string",
      "description": "目标数据库名称"
    },
    "sql": {
      "type": "string",
      "description": "要执行的 SQL 查询语句，仅支持 SELECT / SHOW / DESCRIBE"
    },
    "limit": {
      "type": "integer",
      "description": "返回结果的最大行数，默认 100，上限 1000",
      "default": 100
    },
    "timeout_seconds": {
      "type": "integer",
      "description": "查询超时时间（秒），默认 30",
      "default": 30
    }
  },
  "required": ["database", "sql"]
}
