T1 UnderstandAnythingClient

新建: src/agent_bridge/codegraph/ua_client.py

纯文件系统操作，不依赖外部 CLI，不含网络调用。职责是读取和解析 .understand-anything/ 目录下的产物。

类设计

from dataclasses import dataclass
from pathlib import Path

@dataclass
class UAGraphStatus:
    graph_exists: bool
    graph_path: str | None
    stale: bool               # git commit 与 meta 不匹配
    node_count: int
    edge_count: int
    layer_count: int
    tour_count: int
    analyzed_at: str | None
    git_commit: str | None
    analyzed_files: int | None
    error: str | None         # 解析错误信息

@dataclass
class UAGraphSummary:
    project_name: str | None
    description: str | None
    languages: list[str]
    frameworks: list[str]
    modules: list[dict]       # [{name, summary, file_count}]
    key_nodes: list[dict]     # [{id, name, type, summary}]
    tours: list[dict]         # [{title, description, step_count}]

class UnderstandAnythingClient:

    def status(self, project_dir: Path, current_commit: str | None = None) -> UAGraphStatus:
        """读取 .understand-anything/ 状态。不抛异常，解析失败在 error 字段体现。"""

    def summary(self, project_dir: Path) -> UAGraphSummary | None:
        """读取图谱摘要。图谱不存在返回 None。"""

    def read_graph_raw(self, project_dir: Path) -> dict | None:
        """读取完整 knowledge-graph.json 的原始 dict。供后续 API 或工具使用。"""

实现要点

  • status()：检查 .understand-anything/knowledge-graph.json 是否存在 → 解析 JSON → 统计 nodes/edges/layers/tour → 对比 meta.json 的 gitCommitHash 与传入 current_commit 判断 stale → 任何异常都捕获为 error
  • summary()：读图谱 JSON → 提取 project 字段（name, description, languages, frameworks）→ 聚合 modules（type=module 的 nodes）→ 取 key_nodes（summary 最长的前 10 个非 file 类型节点）→ 提取 tours
  • read_graph_raw()：简单 json.loads()，文件不存在返回 None
  • 所有 JSON 读取用宽松模式：缺失字段用默认值，不因 schema 变化崩溃

新增方法

# service.py — 新增方法

def get_understand_status(self, repo_key: str) -> dict:
    """返回 UA 图谱状态。"""
    repo = self._get_repo(repo_key)           # 复用已有的 repo 查找
    local_path = self._repo_path(repo_key)    # paths.codegraph_dir / repo_key
    current_commit = repo.get("last_commit")
    return self.ua_client.status(local_path, current_commit)

def get_understand_summary(self, repo_key: str) -> dict | None:
    """返回 UA 摘要。图谱不存在返回 None。"""
    self._get_repo(repo_key)
    local_path = self._repo_path(repo_key)
    return self.ua_client.summary(local_path)

修改点

  1. 构造函数注入 UnderstandAnythingClient（可选，默认创建）
  2. 提取 _get_repo(repo_key) 和 _repo_path(repo_key) 内部方法（当前逻辑在 sync_repository 里内联，抽出来复用）
  3. 新增上述两个公开方法

T3 API 路由

修改: src/agent_bridge/api/routes/builtins.py

新增两个只读端点，遵循现有路由模式（factory + call_safely 包装）。

MethodPathHandler返回
GET /code-repo/repositories/{repo_key}/understand/status get_understand_status UAGraphStatus 的 JSON
GET /code-repo/repositories/{repo_key}/understand/summary get_understand_summary UAGraphSummary 的 JSON，图谱不存在返回 404

实现要点

  • 与现有 get_repo_overview 路由结构一致：解析 repo_key path param → 调 service → 返回 JSON
  • summary 端点：图谱不存在时返回 {"error": "understand_graph_not_found"} + 404，而非 500
  • 两个端点都需要 admin 权限（与现有 code-repo 端点一致）

UI 结构

Understand Tab
├── 状态栏（顶部横幅）
│   ├── 图谱不存在 → 灰色提示 "暂无知识图谱"
│   ├── 图谱存在但已过期 → 黄色提示 "图谱可能过期（commit 不匹配）"
│   ├── 图谱正常 → 绿色提示 "知识图谱可用"
│   └── 右侧：节点 N · 边 E · 层 L · 分析时间
│
├── 摘要区（图谱存在时显示）
│   ├── 项目描述
│   ├── 语言 / 框架（tag 展示）
│   ├── 主要模块列表（名称 + 摘要）
│   └── 导览列表（如果有 tour）
│
└── 诊断区（底部，折叠式）
    └── 最近分析 commit、文件数、图谱路径

  • 样式：复用现有 Tab 面板的布局和 shadcn 组件（Badge, Card, Collapsible）
