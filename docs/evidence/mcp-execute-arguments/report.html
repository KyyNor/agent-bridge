方法与边界

  • 旧网关来自提交 04c311d；新侧使用本次源码。工具声明和提示词相同，不提前告知模型容错规则。
  • 六个工具覆盖代码文本、嵌套对象、数组、null、枚举、oneOf、对象型 path、路由字段与业务参数重名。
  • REAL：Codex/CMD 的模型会话和 MCP stdio 传输。MOCKED：业务工具仅检查参数的完整值，不执行代码、SQL或发布文件。
  • 每个模型每侧只有一个短会话，业务参数直接给定；没有模拟 200k 历史、内网量化、并发及复杂参数推导。不能外推为模型选型结论。
  • 初次 CMD 因测试工具未预授权而被拒的准备运行已排除；修复仅在临时项目预授权两个模拟工具。原始 CLI 输出保留本机临时目录，不提交。
  • 耗时包含启动、网络和排队，不报告性能提升。工具效果以服务端调用记录为准，不依赖模型自报。

实现验证

52 个领域测试通过：参数兼容、原有 MCP 工具、HTTP 网关、工作流 MCP、业务台账 MCP。覆盖协议 isError、零副作用、Schema 引用、布尔/数字冲突以及审计 log_id。

建议采用新入口的无歧义容错。模型测试暂未复现日常上下文中的错误，因此本报告证明的是兼容与拒绝边界，不是自然错误率下降。
