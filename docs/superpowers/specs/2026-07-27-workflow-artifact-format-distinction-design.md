# 工作流产物格式区分设计

## 目标

让用户在“工作流产物”列表中无需阅读路径或猜测 tag 含义，即可区分 Markdown 与 HTML 产物，并能按格式筛选。

## 范围

- 产物行的格式 tag 统一显示为“Markdown 文档”或“HTML 文档”。
- tag 带格式对应的 Lucide 图标，并使用不同的语义色。
- 检索区域提供“全部 / Markdown 文档 / HTML 文档”的格式筛选。
- 筛选条件传递给既有的 `searchWorkflowArtifacts` 后端接口；切换格式时重置至第一页。
- 不新增预览、缩略图或详情页行为。

## 设计

`WorkflowArtifactBrowser` 负责展示筛选控件及每行的格式标记；它通过受控属性和事件把格式选择交给父页面。

`useWorkflowArtifacts` 保存当前格式值，搜索时将 `all`、`markdown` 或 `html` 原样传给现有 API。这样结果总数、分页和树形列表均只针对当前格式，而不是在前端对当前页内容二次过滤。

格式标记使用已有的 `@lucide/vue` 图标库：Markdown 使用 `FileText`，HTML 使用 `CodeXml`。两种 tag 都保留清晰文字，颜色仅用于增强扫读，不作为唯一信息来源。

## 错误处理与兼容性

- 未选择格式时继续请求 `format=all`，维持既有结果。
- API 搜索失败仍复用现有错误提示和加载状态。
- 不改变产物详情、历史、文件夹折叠或“查看”操作。

## 验证
